## 🚀 Featured Projects

### 🩺 Project 01 — AI-Powered Multi-Model Disease Diagnostic System
Built an end-to-end diagnostic pipeline achieving up to **98% accuracy** in detecting 8 critical diseases across CT, MRI, X-ray, ultrasound, and fundus images, using VGG16, CNN, and Transfer Learning. Includes Grad-CAM visualization, automated PDF report generation, and email-based result sharing through a lightweight desktop/web application.

**Tech Stack:**
`Python` `VGG16` `CNN` `Transfer Learning` `Grad-CAM`

[🔗 View Repository](https://github.com/abdulrahman-git/Multi-Model-Disease-Diagnostic-System.git)

---

### 🔥 Project 02 — Fire Detection Enhancement System
Enhanced a real-time fire detection system using Python and OpenCV, improving detection accuracy by **20%**. Built an image-processing pipeline across fire/non-fire datasets, with automated valve control, event logging, and email alerts that cut emergency response time by **15%**.

**Tech Stack:** `Python` `OpenCV`

[🔗 View Repository](https://github.com/abdulrahman-git/Fire-Detection-Enhancing-Project.git)

---

### 📝 Project 03 — Mock Test Examination Portal
Developed responsive UI components for a mock test examination platform using React.js, reducing page navigation time by **20%**. Implemented authentication, a timed test interface, and performance tracking, supporting 50+ concurrent mock test sessions.

**Tech Stack:**
